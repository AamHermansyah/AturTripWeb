# AturTrip — petunjuk agen monorepo

Mulai dari [peta dokumentasi](.docs/README.md), lalu baca `AGENTS.md` di aplikasi yang sedang dikerjakan: `apps/web`, `apps/api`, atau `apps/web-admin`. Dokumen aplikasi adalah sumber utama untuk tugas aplikasi itu. Aturan produk lintas aplikasi ada di `.docs/shared/`.

- Baca dokumen sesuai tugas saja; jangan memuat semua PRD/TDD dari tiga aplikasi untuk setiap perubahan.
- Kode menunjukkan kondisi implementasi; checklist menunjukkan kriteria yang terbukti, bukan janji bahwa fitur sudah siap produksi.
- Setelah fitur selesai dibuat dan diverifikasi, tanyakan kepada pengguna apakah fitur sudah selesai tanpa perbaikan. Jika jawabannya ya, langsung perbarui checklist aplikasi dan dokumen terkait. Jika belum, lanjutkan perbaikannya. Jangan menganggap diam sebagai persetujuan.
- Saat membutuhkan keputusan produk dari pengguna, gunakan pertanyaan pilihan interaktif berbentuk bubble bila tersedia. Tawarkan 2–3 opsi yang jelas, taruh saran agen paling dulu, dan beri ruang jawaban bebas. Ajukan satu pertanyaan setiap kali bila pengguna perlu waktu berpikir; **jangan akhiri giliran saat bubble masih menunggu jawaban**, karena popup dapat hilang.
- Seluruh teks antarmuka pengguna memakai Bahasa Indonesia. Utamakan mobile web pada aplikasi wisatawan.
