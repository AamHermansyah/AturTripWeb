# Fase mockup — ringkasan lintas aplikasi

Checklist layar dan review rinci: [apps/web](../../apps/web/.docs/timeline.md) dan [apps/web-admin](../../apps/web-admin/.docs/timeline.md). `[x]` berikut berarti keberadaan awal, bukan persetujuan final.

- [x] UI awal wisatawan mencakup eksplorasi, detail trip, booking, profil, akun, serta halaman grup.
- [ ] Mockup editor pemandu untuk kegiatan, pin mandiri/terkait, segmen rute bertitik belok, dan pratinjau peta publik/booking dapat direview.
- [ ] Mockup detail trip menyatukan interaksi linimasa-peta, rincian segmen, dan penanda lokasi perkiraan pada layar ponsel.
- [ ] Mockup linimasa menunjukkan jam mulai/selesai kegiatan yang berubah sesuai slot terpilih, termasuk trip lintas hari dan kegiatan sesaat (`D-104`, `D-105`).
- [ ] Alur pemandu individu dan pengelolaan grup/agensi dapat direview dan diterima pengguna.
- [ ] Mockup dashboard pemandu mobile memprioritaskan empat ringkasan, tugas, tiga trip terdekat, dan satu grafik pendapatan; konteks Pribadi/Grup serta batas keuangan peran dapat direview (`D-106`–`D-115`).
- [x] Kerangka project admin terpisah tersedia.
- [ ] Login, dashboard, verifikasi, moderasi, dan sengketa pada web-admin dapat direview dan diterima pengguna.
- [ ] Mockup admin menunjukkan antrean sesuai izin, perbandingan versi listing, alasan revisi/pembatasan, laporan terpisah dari sengketa, dan persetujuan pencairan superadmin (`D-116`–`D-125`).
- [ ] Mockup analitik admin dapat direview: ringkasan pasar, peta/peringkat wilayah dan kategori, corong, pasokan, kualitas, serta tab keuangan superadmin dengan filter, perbandingan, waktu pembaruan, dan ekspor (`D-127`–`D-136`).
- [ ] UI autentikasi dan status izin peran pada kedua aplikasi web dapat direview.
- [ ] UI template pembatalan, batas sengketa 48 jam, dan notifikasi transaksi rilis pertama dapat direview.
- [ ] Seluruh layar dalam cakupan rilis diterima tanpa perbaikan terbuka.
